Введение в Python

Python — это высокоуровневый, интерпретируемый язык программирования общего назначения, созданный Гвидо ван Россумом и впервые выпущенный в 1991 году. Философия языка подчеркивает читаемость кода и простоту синтаксиса, что позволяет программистам выражать концепции в меньшем количестве строк кода, чем это возможно в таких языках, как C++ или Java.

Ключевые особенности Python:

  • Простой и читаемый синтаксис: Код на Python похож на обычный английский язык, что делает его идеальным для начинающих.
  • Интерпретируемый: Код выполняется построчно, что упрощает отладку.
  • Кроссплатформенный: Программы на Python могут работать на Windows, macOS, Linux и других операционных системах без изменений.
  • Большая стандартная библиотека: Python поставляется с обширной библиотекой модулей для решения различных задач.
  • Динамическая типизация: Вам не нужно объявлять тип переменной.

Самая простая программа на Python — это вывод строки "Hello, World!".

print("Hello, World!")

Основы синтаксиса

Синтаксис Python отличается своей лаконичностью. Важнейшей особенностью являются отступы, которые используются для определения блоков кода вместо фигурных скобок, как во многих других языках.

Основные моменты:

  • Отступы: Используйте 4 пробела для каждого уровня отступа. Это не просто стиль, это требование синтаксиса.
  • Комментарии: Однострочные комментарии начинаются с символа #.
  • Переменные: Создаются в момент присвоения им значения. Имена переменных чувствительны к регистру (age и Age — разные переменные). 
# Это комментарий
# Объявление переменной
site_name = "DevLearn"

# Блок кода с отступом
if True:
    print("Это сообщение будет выведено")
    # Этот print находится в том же блоке

print("А это сообщение уже вне блока if")

Переменные и типы данных

Переменные — это контейнеры для хранения данных. В Python есть несколько встроенных типов данных:

  • Текстовый тип: str (строка)
  • Числовые типы: int (целое число), float (число с плавающей точкой)
  • Логический тип: bool (True или False)
  • Последовательности: list, tuple, range
  • Словарь: dict
  • Множества: set

Вы можете узнать тип любой переменной с помощью функции type().

name = "Алиса"      # str
age = 30           # int
height = 1.68      # float
is_active = True   # bool

print(type(name))
print(type(age))
print(type(height))
print(type(is_active))

Функции

Функции — это многократно используемые блоки кода, которые выполняют определенную задачу. Они помогают сделать код более организованным, модульным и читаемым.

Функция определяется с помощью ключевого слова def, за которым следует имя функции и круглые скобки (). В скобках могут быть указаны параметры.

# Простая функция без параметров
def greet():
    print("Привет, добро пожаловать!")

# Функция с параметрами
def add_numbers(a, b):
    result = a + b
    return result # Ключевое слово return возвращает значение

# Вызов функций
greet()
sum_result = add_numbers(5, 7)
print(f"Сумма: {sum_result}")

Структуры данных: Списки

Список (list) — это упорядоченная и изменяемая коллекция элементов. Списки могут содержать элементы разных типов. Они создаются с помощью квадратных скобок [].

Основные операции со списками:

  • Доступ к элементам: по индексу (нумерация с 0). my_list[0]
  • Добавление элемента: my_list.append(item)
  • Удаление элемента: my_list.remove(item) или del my_list[index]
  • Длина списка: len(my_list)
# Создание списка
fruits = ["яблоко", "банан", "вишня"]
print(f"Исходный список: {fruits}")

# Добавление элемента
fruits.append("апельсин")
print(f"После добавления: {fruits}")

# Доступ по индексу
first_fruit = fruits[0]
print(f"Первый фрукт: {first_fruit}")

# Удаление элемента
fruits.remove("банан")
print(f"После удаления: {fruits}")

# Длина списка
print(f"Длина списка: {len(fruits)}")
